# Intermediate Python Programming

This section contains nine programs exploring useful Python features beyond the basics.

## Programs

| No. | Topic | Filename |
|---|---|---|
| 1 | List Comprehensions | `01_list_comprehensions.py` |
| 2 | Lambda, Map and Filter | `02_lambda_map_filter.py` |
| 3 | Iterators and Generators | `03_iterators_generators.py` |
| 4 | Decorators | `04_decorators.py` |

| 6 | File Handling | `06_file_handling.py` |
| 7 | Regular Expressions | `07_regular_expressions.py` |

## Concepts Covered
- List and dictionary comprehensions
- Lambda expressions, map and filter
- Iterators and generators
- Function decorators
- Exception handling
- File reading and writing
- Regular expressions
- Multithreading
- Context managers and resource management

## Objective
To explore intermediate Python features and develop practical programming skills through reusable and efficient code.
