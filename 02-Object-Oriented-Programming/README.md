## Concepts Practiced
- Creating classes and objects
- Constructors and instance methods
- Single and multiple inheritance
- Runtime polymorphism and method overriding
- Data hiding and encapsulation
- Abstract classes and methods
- Class-level and instance-level attributes
- Static methods and class methods
- Method and operator overloading
- Python magic methods
- Composition and object relationships

## Objective
To understand how object-oriented programming helps organize Python applications into reusable, structured, and maintainable components.
